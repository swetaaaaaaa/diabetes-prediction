# Diabetes Prediction System

A machine learning project that predicts diabetes risk using patient health information.

## Features

- Diabetes prediction using machine learning
- Probability of diabetes
- Probability of no diabetes
- Streamlit web interface
- Feature importance analysis

## Machine Learning

The project uses classification algorithms such as:

- Logistic Regression
- Random Forest

## Dataset

The project uses the Pima Indians Diabetes dataset.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
- Matplotlib
